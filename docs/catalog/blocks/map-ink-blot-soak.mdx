## Add it to your video

It runs for 12.01 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="map-ink-blot-soak"
  data-composition-src="compositions/map-ink-blot-soak.html"
  data-start="0"
  data-duration="12.01"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.

## Change how it looks

Set these CSS variables on the block:

- `title` - Title. Defaults to `Archival Map - Ink Blot`.
- `credit` - Credit line. Defaults to `Footage: Moving Image Archive | Oil Across Arabia`.

## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `title` | `Archival Map - Ink Blot` | string |  |
| `credit` | `Footage: Moving Image Archive | Oil Across Arabia` | string |  |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="map-ink-blot-soak"
  data-composition-src="compositions/map-ink-blot-soak.html"
  data-variable-values='{"title":"Archival Map - Ink Blot","credit":"Footage: Moving Image Archive | Oil Across Arabia"}'
></div>
```
