## Add it to your video

It runs for 8 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="map-parchment-fold"
  data-composition-src="compositions/map-parchment-fold.html"
  data-start="0"
  data-duration="8"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.

## Change how it looks

Set these CSS variables on the block:

- `title` - Title. Defaults to `Parchment Chart`.
- `subtitle` - Subtitle. Defaults to `Educational cartography · paper fold`.
- `accent` - Accent. Defaults to `#c45c26`.

## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `title` | `Parchment Chart` | string |  |
| `subtitle` | `Educational cartography · paper fold` | string |  |
| `accent` | `#c45c26` | color |  |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="map-parchment-fold"
  data-composition-src="compositions/map-parchment-fold.html"
  data-variable-values='{"title":"Parchment Chart","subtitle":"Educational cartography · paper fold","accent":"#c45c26"}'
></div>
```
