## Add it to your video

It runs for 8 seconds at 1920×1080. Paste this into your composition:

```html index.html
<div
  data-composition-id="map-split-theater"
  data-composition-src="compositions/map-split-theater.html"
  data-start="0"
  data-duration="8"
  data-track-index="1"
  data-width="1920"
  data-height="1080"
></div>
```

Move it in time with `data-start`. Put it on a different timeline row with
`data-track-index`. See [data attributes](/concepts/data-attributes) for the rest.

## Change how it looks

Set these CSS variables on the block:

- `title` - Title. Defaults to `Two Theaters`.
- `subtitle` - Subtitle. Defaults to `Educational cartography · split screen`.
- `leftTitle` - Left title. Defaults to `WEST`.
- `rightTitle` - Right title. Defaults to `EAST`.
- `accent` - Accent. Defaults to `#c45c26`.

## Variables

Every one of these has a default, so the piece works untouched. Set the ones you
want to change on the element:

| Variable | Default | Accepts | What it does |
| --- | --- | --- | --- |
| `title` | `Two Theaters` | string |  |
| `subtitle` | `Educational cartography · split screen` | string |  |
| `leftTitle` | `WEST` | string |  |
| `rightTitle` | `EAST` | string |  |
| `accent` | `#c45c26` | color |  |

Set them with `data-variable-values` on the element that mounts it. These are the
defaults, so this behaves exactly like the preview above until you change one:

```html wrap
<div
  data-composition-id="map-split-theater"
  data-composition-src="compositions/map-split-theater.html"
  data-variable-values='{"title":"Two Theaters","subtitle":"Educational cartography · split screen","leftTitle":"WEST","rightTitle":"EAST","accent":"#c45c26"}'
></div>
```
