# Credits - Animated Maps pack

This pack contains only real Moving Image Archive Animated Maps footage.
Footage-only video compositions (not drawn SVG maps).

Collection: https://www.movingimagearchive.com/collection/animated-maps
About: material is drawn from public-domain collections and is free to reuse.

Acquisition: `https://www.movingimagearchive.com/api/clips/<clip-id>/download`
Self-hosted under each item `assets/clip.mp4`.

Credit format: `Moving Image Archive, [title], [year]; producer/collection; archive.org`

Pre-existing catalog maps (`world-map`, `us-map`, `spain-map`, etc.) are unrelated and kept.
