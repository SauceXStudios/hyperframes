# HyperFrames v0.8.38

Released on 2026-09-14.

Starting a project now gives a centered title on a dark frame with no extra flags. Local renders use the faster capture path. Agents writing a composition get the HTML contract only.

## Features

- **CLI:** `hyperframes init` scaffolds a centered title. Local render defaults to BeginFrame. `looks` is a named quality preset ([f059a6eb5](https://github.com/heygen-com/hyperframes/commit/f059a6eb539e6289d20156f04eb04a43ddc8b806), [#3927](https://github.com/heygen-com/hyperframes/pull/3927)).

## Skills

- **Authoring:** The core skill is how to write composition HTML. Briefing and review docs live on the router skill ([95bea1631](https://github.com/heygen-com/hyperframes/commit/95bea1631ff51dd38332f69daef3a1e1849d51c6), [#3928](https://github.com/heygen-com/hyperframes/pull/3928)).
